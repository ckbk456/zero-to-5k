# Roadmap

## Scaffold

Implemented: native home screen, SQLite activity selection and migration, host SQL tests, repository workflow, CI definitions, public research. Results live in [bootstrap](bootstrap.md). Device QA, final identity/icon, and license selection remain pending.

## Native workout feasibility

Prove locked-screen interval cues alongside music/podcasts on physical iPhone and Android: silent gaps, interruptions, pause/resume, termination, permissions, and battery. Select an iOS mechanism from measured evidence. No training promise should depend on an untested runtime.

## Guided sessions

Review activity-specific curricula, technique cues, intensity, and repeat/regress policies. Define immutable session snapshots/history and append database migrations. Implement time-based sessions and progress after the execution contract is clear.

## Personalization

Evaluate requested program length using reviewed templates and explicit constraints. Add maintenance after the time goal. Optional distance/performance and cloud sync remain separate scope.

## Release gates

Resolve dependency advisories, build signed apps, select store identifiers, review privacy/backup behavior, complete accessibility/device QA and curriculum review, and obtain explicit release authority. Public repository publication is not an app release.
