# Contributing

Read [AGENTS.md](AGENTS.md), [product](docs/logic/product.md), and [architecture](docs/logic/architecture.md). Install the pinned Node/npm versions and use `npm ci`.

Use an isolated `codex/<task>` branch/worktree from verified `origin/main`. Keep each change reviewable, update the owning logic and [manual guide](testing/MANUAL%20TO-DO/README.md), and run the [documented gates](docs/commands.md).

Keep credentials, private research originals, device databases, sensitive recordings, and generated builds out of commits. No cloud account is needed for this scaffold. Use the PR template and distinguish automated checks from device evidence. Publication, merge, and release are separate authorities.
